The PDT canvases, in pdt42

You know the canvases of the Platform Design Toolkit. Here is each one as Boundaryless publishes it, next to the canvas pdt42 draws from the model of Harvest Commons. The table under each pair tells you which block and field fills which area of the canvas, so you can write down what you would have put on a sticky.
